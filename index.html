05 · How It Works

From raw data to a price you can plan around

The system combines a historical price database, a trained machine learning model, and current economic indicators to produce short and long-term fuel price estimates.

1
Collect historical data

Daily petrol and diesel prices, crude oil rates, USD-INR rates, inflation and tax data are stored in MySQL.

2
Engineer features

Scikit-learn preprocesses the raw series into model-ready features: lagged prices, rolling averages and rate-of-change signals.

3
Train the Random Forest

An ensemble of decision trees learns how crude oil, forex, inflation, tax and demand-supply patterns have historically moved prices.

4
Serve predictions via Flask

The trained model is wrapped in a Flask API that accepts a fuel type, location and horizon, and returns an estimated price.

5
Visualize on the dashboard

Chart.js renders the historical trend, comparison and forecast so the result is easy to read at a glance.
